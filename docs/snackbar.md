# 안내 메시지(스낵바) 사용 현황

스낵바(하단에 잠깐 뜨는 안내)를 어디에서 어떤 문구로 쓰는지 모은 표. 2026-10-23 기준 (`ScaffoldMessenger … showSnackBar` + `_snack` 도우미).

판단 기준: 화면이 이미 결과를 보여 주면(버튼 모양이 바뀜, 줄이 사라짐, 화면이 닫힘) 스낵바는 겹치는 안내라 **빼는 쪽**.
결과가 화면에 안 보이거나(실패 · 막힘 · 다른 화면으로 떠남) 사용자가 다음에 할 일이 있으면 **둔다**.

## A. 둔다 — 실패 · 막힘 · 해야 할 일 안내

| 위치 | 문구 |
|---|---|
| 앱 전체(app_shell) | 미리 듣기를 시작하지 못했어요 + 까닭 |
| 받기 팝업(download_dialog) ×2 | 이미 받는 중이거나 대기 중인 곡이에요 |
| 곡 메뉴(track_menu) | 설정에서 "다른 앱 위에 표시"를 허용한 뒤 다시 켜 주세요 |
| 곡 메뉴 | 음악 파일에 곡 정보를 쓰지 못해 바꾸지 않았어요 |
| 곡 메뉴 | 파일을 지우지 못했어요. 권한을 확인한 뒤 다시 시도해 주세요 |
| 앨범 화면(album_screen) | 음악 파일에 곡 정보를 쓰지 못해 바꾸지 않았어요 |
| 가사 웹(lyrics_web_screen) ×2 | 고른 글이 없어요 · 모은 글이 없어요 |
| 가사 싱크 시작(lyrics_sync_start) | 싱크를 맞출 가사가 없어요 |
| 재생목록 불러오기(playlist_import) ×2 | 구글 로그인 설정값이 없어요 · 로그인하지 못했어요 |
| 재생목록 메뉴(playlist_menu) | 재생할 곡이 없어요 |
| 곡 자세히(media_detail) | 열 수 있는 앱이 없어요 |
| 검색(search_screen) | 클립보드에 링크가 없어요 |
| 미리 듣기(preview_control) | 이 기기에서는 미리 듣기를 쓸 수 없어요 · 서버에 연결하지 못했어요 |
| 채널 구독(channel_search · channel_info · subscribe_button) | 이 채널은 구독할 수 없어요 |

## B. 둔다 — 결과가 화면에 안 보이는 성공 안내

| 위치 | 문구 | 이유 |
|---|---|---|
| 받기 시작(new_videos_sheet · launcher · playlist_import) | N곡을 받기 시작했어요 / 이미 받은 곡이라 새로 받을 곡이 없어요 | 받기 대기열은 다른 곳에 있다 |
| 보관함(library_screen) | N곡을 불러왔어요 / 새로 추가된 곡이 없어요 | 불러오기가 끝난 시점을 알려 줘야 한다 |
| 재생목록 고르기(playlist_pick) | N개 재생목록에 담았어요 | 화면이 닫혀 결과가 안 보인다 |
| 앱 시작(new_videos_launcher) | 구독 채널에 새 영상이 N개 있어요 + [보기] | 눌러서 가는 동작이 붙어 있다 (스낵바보다 상단 배너가 어울린다) |
| 채널 구독 | 구독했어요. 지금부터 올라오는 영상을 알려 드려요 | 버튼은 바뀌지만 알림 안내가 들어 있다 (첫 구독에만 보여 주는 것도 방법) |

## C. 뺐다 (2026-10-23 적용) — 화면이 이미 결과를 보여 줘서 겹치는 안내

| 위치 | 문구 | 화면이 보여 주는 것 |
|---|---|---|
| 곡 메뉴 | **다음에 재생해요** | 대기열에서 확인 가능, 메뉴가 닫히며 끝 |
| 곡 메뉴 | 대기열에 추가했어요 | 대기열에서 확인 가능 |
| 곡 메뉴 | 대기열에서 뺐어요 | 줄이 사라진다 |
| 곡 메뉴 | 재생목록에서 뺐어요 | 줄이 사라진다 |
| 곡 메뉴 | 삭제했어요 | 줄이 사라진다 |
| 곡 메뉴 | 곡 정보를 고쳤어요 | 제목 · 아티스트가 바뀐다 |
| 곡 메뉴 | 좋아요 / 좋아요 취소 | 하트 모양이 바뀐다 |
| 대기열(queue_screen) | 대기열을 비웠어요 | 목록이 비고 안내가 나온다 |
| 재생목록 메뉴 | 재생목록을 지웠어요 | 목록에서 사라진다 |
| 앨범 화면 | 앨범 이름을 바꿨어요 | 제목이 바뀐다 |
| 가사 편집(lyrics_editor · lyrics_sync_start) | 가사를 저장했어요 / 지웠어요 | 시트가 닫히고 가사가 바뀐다 |
| 채널 구독 | 구독을 해제했어요 | 버튼이 "구독"으로 돌아온다 |
| 플레이어(player_common) | N분 뒤 재생을 멈춰요 / 수면 타이머를 껐어요 | 타이머 버튼 모양이 바뀐다 |

## 정리

- 처음엔 파일 21개, 호출 약 45곳이었다. C 묶음(약 15곳)을 뺐고 A · B만 남았다. 어색하면 C에서 다시 살리거나 더 뺀다 (문구는 ARB에 그대로 있다).
- 스낵바 모양(떠 있는 둥근 알림)은 `lib/core/design/app_theme.dart`의 `snackBarTheme`에서 한 곳으로 정한다.
