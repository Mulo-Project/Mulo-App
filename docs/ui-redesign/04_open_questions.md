# 04. 사용자에게 물을 것

1. **PC 캡처**: `flutter test --run-skipped -t screenshot test/screenshots` 결과(PNG)를 나중에 받을 수 있나? 없으면 모든 판단은 코드 기반 추정으로 남는다. (정확한 밀도 · 640px 판단이 필요한 항목만 후순위)
2. **첫 작업 단위**: 테마 감사(대비 계산이 코드로 가능, 캡처 불필요)부터 시작해도 되나, 아니면 버튼/TrackTile 같은 컴포넌트 외형을 먼저 볼까?
3. **하단 네비 홈 강조**: 가운데 홈만 강조 원을 유지할지, 동등한 탭으로 바꾸는 안도 비교할지.
4. **카드 정책**: 현재 규칙은 "카드는 보관함 · 재생목록에만". 리디자인에서도 이 규칙을 그대로 유지할까?
5. **라이트 모드 비중**: 라이트에서 대비가 부족한 프리셋이 나오면 색을 보정할지, 해당 프리셋의 라이트를 제한할지.
6. **신규 UI 허용 범위**: 설정 검색/목차, 드래그 안내 문구 같은 "신규 보조 UI"를 제안에 포함해도 되나 (기본은 기존 요소 재배치만).
7. **산출물 형태**: 승인 단계에서 이미지가 필요하면 와이어프레임(SVG)만으로 충분한가, Figma로 옮길까?
8. **플랫폼**: 현재 Android만 대상이라고 이해하고 있다. 데스크톱/iOS 레이아웃은 이번 범위에서 제외해도 되나.
