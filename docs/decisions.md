## D-004 · 2026-09-29 · 테마는 교체 가능한 소스로
위젯은 색을 토큰에서만 읽고, 테마는 `ThemeSource`(기본 · 사용자 지정 · 곡 분위기)가 만든 팔레트로 바뀐다.
전환은 `ThemeExtension.lerp`로 애니메이션. 곡 분위기 · 사용자 지정 테마에서도 배경은 검정 유지, 강조 색은 배경 대비 7:1 이상으로 보정.
이유: 나중에 사용자 지정 · 곡 분위기 테마를 화면 수정 없이 붙이기 위해.

## D-005 · 2026-09-29 · 곡 분위기 테마는 설정이 켜져 있을 때만
"곡 분위기 따라가기" 설정이 켜져 있을 때만 `MoodThemeSource`를 적용하고, 꺼져 있으면 사용자 지정(없으면 기본) 테마.
분기 구현은 설정 화면을 만들 때 한다. 지금은 소스 구조만 있음.

## D-006 · 2026-09-29 · 글꼴 Pretendard
Pretendard v1.3.9 (SIL OFL 1.1), 400 · 500 · 600 · 700 네 굵기만 `assets/fonts/pretendard/`에 넣는다 (OTF, 약 6MB).

이유: 한글 가독성, 오픈 라이선스라 GitHub 공개 · 배포 가능.

## D-012 · 2026-09-29 · 글래스 스타일 (D-003의 점 모양 대체)
사용자 피드백: 점(도트) 느낌이 아니라 유리 느낌.
- 배경: 점 격자 → 검정 + 테마 색 빛 번짐(`AppBackground`)
- 면: 뒤를 흐리게 비추는 반투명 유리 + 왼쪽 위 빛 테두리(`GlassSurface` · `GlassCard`). 카드 · 설정 묶음 · 입력칸 · 버튼 · 미니 플레이어 · 탭 바
- 숫자: LED 점 숫자 → Pretendard 큰 숫자(`StatNumber`)
- 진행 표시: 점선 → 매끈한 선 + 강조 색 빛(`ProgressRing` · `ProgressLine`)
- 미니 플레이어 · 탭 바는 떠 있는 유리, 내용이 그 뒤로 흘러간다(`extendBody`)
팔레트 · 테마 소스 구조(D-004)는 그대로.
→ 유리 범위는 D-015로 좁힘.

## D-013 · 2026-09-29 · 테마 색 프리셋 8개 (저장)
사용자 요청: 테마를 여러 색으로 고를 수 있게.
프리셋 8개(바이올렛 기본 · 코랄 · 오션 · 포레스트 · 선셋 · 로즈 · 골드 · 아이스)를 설정에서 색 동그라미로 고른다.
고른 값은 `shared_preferences`에 저장. 곡 분위기 테마(D-005)가 꺼지면 고른 프리셋으로 돌아간다.
직접 색을 고르는 사용자 지정(CustomThemeSource)은 나중에 필요하면 추가.

## D-014 · 2026-09-29 · 곡 · 재생목록 커버 이미지 등록
사용자 요청: 재생목록 · 음원에 맞는 이미지를 등록할 수 있게.
- 곡(보관함 ⋮ 버튼, 플레이어 커버 · 편집 버튼)과 재생목록(카드의 이미지 버튼)에서 "커버 이미지" 시트 → 사진에서 고르기 / 기본 이미지로.
- 이미지 고르기는 `file_picker`의 `pickFile(type: image)` (Android는 시스템 사진 선택기라 저장소 권한 불필요, 데스크톱은 파일 대화상자).
- `CoverController`가 키(`track:<id>` · `playlist:<id>`) → 파일 경로를 가진다. 지금은 앱 실행 중에만 기억하고,
  보관함 DB(drift)를 붙일 때 고른 파일을 앱 폴더로 복사 · DB에 경로 저장으로 바꾼다.
- 시트는 탭 틀 위로 뜨도록 최상위 내비게이터(`useRootNavigator`)에서 연다.

## D-015 · 2026-09-30 · 유리는 일부 버튼 · 카드에만, 이미지 카드는 유리 없이
사용자 피드백: 배경까지 유리 느낌일 필요 없음, 일부 버튼 · 카드만. 재생목록은 이미지를 넣으니 유리 불필요.
- 배경: 테마 색 빛 번짐 제거 → 단색 (다크 / 라이트는 D-016)
- 유리 유지: 미니 플레이어 · 하단 탭(떠 있는 바), 원형 버튼 · tonal 버튼, 강조 카드(보관함 · 다운로드 요약, 검색 결과)
- 평범한 면으로: 설정 묶음 · 입력칸 · 선택 알약 · 스위치
- 재생목록 카드 · 플레이어 커버: `CoverCard` (사진, 없으면 테마 색 그라데이션, 유리 없음)
- 팔레트에 `onGlow`(색 · 사진 위 글자) · `scrim`(사진 어둡게) 추가

## D-017 · 2026-09-30 · 보관함 DB(drift) · 기기 음악 불러오기
- 앱 로컬 DB는 drift(SQLite, `drift_flutter`): `lib/core/database/app_database.dart`. 표: `tracks`(재생 주소 uri 유일), `covers`(키 → 앱 폴더로 복사한 이미지 경로).
- 보관함 화면은 가짜 데이터 대신 DB를 본다. 재생 대기열도 처음엔 비어 있다 (미니 플레이어 숨김).
- 기기 음악 불러오기(#11):
  - Android: 명세대로 MediaStore를 네이티브에서 조회 (`MediaStoreChannel.kt`, MethodChannel `music_app/media_store`). 권한은 `permission_handler`(13+ READ_MEDIA_AUDIO, 12 이하 READ_EXTERNAL_STORAGE).
  - 데스크톱: 폴더를 고르면 하위 폴더까지 음악 확장자 파일을 찾는다. 태그는 아직 안 읽고 파일 이름이 제목.
  - 같은 uri는 다시 넣지 않는다. 결과는 스낵바로 (n곡 추가 · 새 곡 없음 · 권한 필요 · 실패).
- 커버 이미지(D-014)는 이제 앱 지원 폴더 `covers/`로 복사 + DB 저장 → 다시 켜도 유지.
- `permission_handler` 13이 compileSdk 37을 요구해서 `android/app/build.gradle.kts`의 compileSdk를 37로.
- 라이트 모드 색 유리 카드는 옅게(`AppGlass.tintOpacityLight`) 칠하고 글자는 기본 글자색 (카드 안 글자색이 섞이던 문제 수정).

## D-019 · 2026-10-01 · 클린 아키텍처 + BLoC (D-002 대체)
사용자 요청: 앱 기능이 많고 규모가 커서 클린 아키텍처 + BLoC.
- 상태 관리 `flutter_bloc`(Cubit 우선, 이벤트가 복잡하면 Bloc), 의존성 주입 `get_it`. Riverpod 제거.
- 기능별 domain(entities · repositories · usecases, 순수 Dart) / data(datasources · repositories) / presentation(bloc · screens · widgets).
- 테마도 기능으로 분리(`features/theme`): 저장 설정은 domain(`ThemeSettings` · `AppThemeMode`), 색 팔레트 계산은 presentation(`ThemeCubit` + core/design).
- 앱 전체 bloc(테마 · 커버 · 보관함 · 불러오기 · 재생)은 MaterialApp 위 MultiBlocProvider → 바텀시트 · 전체 화면 플레이어에서도 읽힌다.
- 의존 규칙은 `test/architecture_test.dart`가 검사.
