# 설계 결정 기록

새 결정은 맨 아래에 추가한다. 형식: 번호 · 날짜 · 결정 · 이유. 바뀐 결정은 지우지 않고 "→ D-0xx로 대체"라고 적는다.

## D-001 · 2026-09-29 · 문서 위치
작업 규칙은 루트 `CLAUDE.md`, 프로젝트 문서는 `docs/`, 작업 기록은 `docs/worklog/`(작업 하나 = 파일 하나).
기능 명세 원본은 Notion, 작업 기록은 Notion 작업 현황 DB에 한 행씩 옮긴다.

## D-002 · 2026-09-29 · 상태 관리 Riverpod
`flutter_riverpod`(코드 생성 없이 `Notifier`). Notion 기술 스택과 같음.

## D-003 · 2026-09-29 · 디자인 방향
검정 배경 + 옅은 점 격자, 둥근(32) 그라데이션 글로우 카드, 점 행렬(LED) 숫자, 알약 버튼, 원형 아이콘 버튼.
기본 팔레트: 검정 #000000 · 바이올렛 #7D39EB · 라임 #C6FF33 · 흰색 #FFFFFF. 상세는 [design-system.md](design-system.md).
→ 모양(점 격자 · 점 숫자 · 점선)은 D-012로 대체. 팔레트는 유지.

## D-004 · 2026-09-29 · 테마는 교체 가능한 소스로
위젯은 색을 토큰에서만 읽고, 테마는 `ThemeSource`(기본 · 사용자 지정 · 곡 분위기)가 만든 팔레트로 바뀐다.
전환은 `ThemeExtension.lerp`로 애니메이션. 곡 분위기 · 사용자 지정 테마에서도 배경은 검정 유지, 강조 색은 배경 대비 7:1 이상으로 보정.
이유: 나중에 사용자 지정 · 곡 분위기 테마를 화면 수정 없이 붙이기 위해.

## D-005 · 2026-09-29 · 곡 분위기 테마는 설정이 켜져 있을 때만
"곡 분위기 따라가기" 설정이 켜져 있을 때만 `MoodThemeSource`를 적용하고, 꺼져 있으면 사용자 지정(없으면 기본) 테마.
분기 구현은 설정 화면을 만들 때 한다. 지금은 소스 구조만 있음.

## D-006 · 2026-09-29 · 글꼴 Pretendard
Pretendard v1.3.9 (SIL OFL 1.1), 400 · 500 · 600 · 700 네 굵기만 `assets/fonts/pretendard/`에 넣는다 (OTF, 약 6MB).
큰 숫자는 글꼴 대신 `DotMatrixText`(직접 그림).
이유: 한글 가독성, 오픈 라이선스라 GitHub 공개 · 배포 가능.

## D-007 · 2026-09-29 · Git 브랜치 · 커밋 규칙
`main` · `develop` + 작업 브랜치, 커밋 `<type>(<scope>): 한국어 요약`. 명세의 상세 기능은 ID에 접두어가 없어 scope는 영역 이름으로 쓰고, 관련 상세 기능은 커밋 본문 `Refs:`에 적는다. 상세는 [git.md](git.md).

## D-008 · 2026-09-29 · 서버는 별도 저장소
Spring Boot 서버는 이 저장소가 아니라 다른 저장소에서 작업한다. 이 저장소는 Flutter 앱만 담는다.
앱 ↔ 서버 계약은 Notion API 명세를 기준으로 맞춘다.

## D-009 · 2026-09-29 · 라우팅 go_router, 하단 탭 5개
`go_router` `StatefulShellRoute`로 탭마다 스택 유지. 탭: 보관함(첫 화면) · 재생목록 · 검색 · 다운로드 · 설정.
미니 플레이어는 탭 바 위에 항상, 누르면 전체 화면 플레이어(`/player`)가 아래에서 올라온다.
`/search?q=`로 입력칸을 채워 연다 (공유 메뉴로 받기 #4).

## D-010 · 2026-09-29 · 다국어 ARB (한국어 기본, 영어)
`flutter_localizations` + gen-l10n, `lib/l10n/app_ko.arb`(템플릿) · `app_en.arb`. 화면 문구는 `context.l10n`으로만.
지원하지 않는 기기 언어는 한국어. 디자인 미리보기(개발용) 화면만 예외.

## D-011 · 2026-09-29 · UI 먼저 (자리 표시 데이터)
MVP 화면을 `lib/core/sample/sample_data.dart`의 가짜 데이터로 먼저 만들고, 확인 · 피드백 후 기능을 연결한다.
가짜 데이터에 실제 곡 · URL을 쓰지 않는다. 기능이 연결되면 샘플을 리포지토리로 바꾸고 지운다.

## D-012 · 2026-09-29 · 글래스 스타일 (D-003의 점 모양 대체)
사용자 피드백: 점(도트) 느낌이 아니라 유리 느낌.
- 배경: 점 격자 → 검정 + 테마 색 빛 번짐(`AppBackground`)
- 면: 뒤를 흐리게 비추는 반투명 유리 + 왼쪽 위 빛 테두리(`GlassSurface` · `GlassCard`). 카드 · 설정 묶음 · 입력칸 · 버튼 · 미니 플레이어 · 탭 바
- 숫자: LED 점 숫자 → Pretendard 큰 숫자(`StatNumber`)
- 진행 표시: 점선 → 매끈한 선 + 강조 색 빛(`ProgressRing` · `ProgressLine`)
- 미니 플레이어 · 탭 바는 떠 있는 유리, 내용이 그 뒤로 흘러간다(`extendBody`)
팔레트 · 테마 소스 구조(D-004)는 그대로.

## D-013 · 2026-09-29 · 테마 색 프리셋 8개 (저장)
사용자 요청: 테마를 여러 색으로 고를 수 있게.
프리셋 8개(바이올렛 기본 · 코랄 · 오션 · 포레스트 · 선셋 · 로즈 · 골드 · 아이스)를 설정에서 색 동그라미로 고른다.
고른 값은 `shared_preferences`에 저장. 곡 분위기 테마(D-005)가 꺼지면 고른 프리셋으로 돌아간다.
직접 색을 고르는 사용자 지정(CustomThemeSource)은 나중에 필요하면 추가.
