## 성능
- 보관함 아티스트 · 앨범 · 장르 탭을 보이는 줄만 만드는 지연 로딩으로.
- 가사 보기: 재생 위치(0.25초) 대신 "지금 줄 번호"만 구독, 플레이어 화면이 틱마다 다시 그려도 가사 보기를 다시 만들지 않음, 가운데 한 줄 테마의 흐림 띠 제거.
- 받기 띠 · 미니 플레이어 · 받기 플로팅 버튼 · 플로팅 플레이어 버튼의 유리 흐림(BackdropFilter)을 `GlassSurface(solid: true)`로 대체 (D-121: 성능이 유리 효과보다 먼저).
- 가사 전체화면이 곡이 바뀔 때만 다시 그림.

## 공용 위젯 (core/design/components)
- `LoadingIndicator` · `LoadingState`(원형) · `LoadingBar`(얇은 막대: 곡 자세히 · 가사 웹 · 커버 웹).
- `EmptyState`: 빈 안내 + `.network`(연결 필요) + `.signIn`(로그인 필요), `compact` · `iconSize`, 항상 가운데.
- `AppBackButton` · `AppDivider` · `SectionTitle` · `ExpandableText`(긴 설명 더 보기/접기).
- `showConfirmDialog`: 예·아니오 확인창 하나 (대기열 비우기 · 재생목록 삭제 · 받기 취소 · 엔진 삭제 · 가사 싱크 확인).
- `AppDropdown`: 정렬 방향 화살표를 알약에 붙임 (`onToggleDirection`).
- `AppTopBar`: 버튼이 둘 이상이면 앞 버튼 · 제목 · 버튼들 한 줄 배치로 (앨범 · 재생목록 상세에서 제목이 깨지던 것).
- `ColorPicker`: 견본 한 줄 + 접힌 "색상 직접 고르기"로 비중 축소.
- `MarqueeText`: 멈춤 없이 이어서 흐름.
- 기본 커버는 `GlowTone.neutral` 무채색 (이미지 · 색을 정하지 않은 곡 · 앨범 · 아티스트 · 장르 · 재생목록).
- covers 기능: `CoverEntry`(이미지 줄) · `CoverSettingsSection`(이미지 + 색) · `ChannelHeader` · `ChannelSettingsSections`(구독 채널 시트 공통).
- library 기능: `TrackGroupScreen`(앨범 · 아티스트 · 장르 화면 공통) · `showProgressWhile`(진행 대화상자).

## 디자인 · 화면
- 빈 상태 · 연결 필요 · 로그인 필요 안내를 한 모양으로 통일하고 홈 · 보관함 · 검색 · 대기열 · 재생목록 · 가사 · 구독 · 저장 폴더 등에서 가운데에 놓음.
- 이미지 페이지 하나로 통일 (곡 · 앨범 · 아티스트 · 재생목록 · 받기): 제목 "이미지", 현재 이미지를 불러온 채 열림, 이미지가 없으면 확대 · 회전 · 적용 숨김, "위치 되돌리기 · 기본 이미지로 · 이미지 지우기"는 한 줄의 같은 버튼(확인창 거침).
- 구독 채널: 버튼 같은 너비 나란히, 임시 확인 버튼은 디버그 빌드에서만, 채널 시트 머리 통일 · 분류 2열 표 · 구독 중 표시 · 읽는 중 막대 · 채널 소개 전체 읽기, 새 영상 시트(요약 · 채널 묶음 머리 · 16:9 썸네일).
- 재생목록 불러오기: 안내마다 아이콘, 돌아가기 · 모두 선택을 글자 버튼으로, "내 재생목록" 버튼 전체 너비.
- 재생목록 상세: 대표곡을 카드에서 빼고 상세로, 빈 안내는 큰 제목 + 작은 설명(좋아요 목록은 하트 아이콘과 다른 문구).
- 플레이어 하단 조작부를 화면 높이의 1/3 이하로 (낮은 화면은 비율 유지로 줄임).
- 스낵바 정리: 화면이 이미 결과를 보여 주는 안내 제거, 실패 · 막힘만 유지 (`docs/snackbar.md`). 앱 시작 새 영상 안내는 위에서 내려오는 안내 줄(`NewVideosBanner`)로.
- 홈: 최근 들은 곡 요약 카드의 헤드폰 아이콘 제거, 접기 구역 화살표를 곡 줄 ⋮ 와 세로선 맞춤.

## 기능
- 곡 정보 편집은 파일 태그에 먼저 쓰고 성공하면 DB 저장 (D-120, 태그 먼저 쓰기).
- 보관함 정렬에 오름차순 / 내림차순 전환 (탭마다 기억, 기준을 바꾸면 기본 방향으로).
- 검색: 찾는 중에 글자를 고치거나 지우면 로딩을 멈추고 이전 결과로 복귀.
- 설정: 앱이 받아 둔 yt-dlp 삭제 버튼(데스크톱, 확인창). Android는 앱 안 내장이라 해당 없음.
- 재생목록: 곡 추가(보관함과 같은 탭, 묶음 펼쳐 곡마다 선택, 검색 · 모두 선택), 카드 순서 바꾸기(길게 눌러 끌기).
- 대기열: 반복 버튼(끔 → 전체 → 한 곡).
- 아티스트 · 장르 이름 바꾸기(앨범은 이미 있음), 곡이 4곡 이상이면 진행 대화상자.
