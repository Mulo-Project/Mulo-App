# 앱 아이콘 적용

- 날짜: 2026-11-15
- 분류: 디자인 · 설정
- 상태: 완료 (PR 대기)
- 브랜치 · 커밋: `chore/app-icon`
- 상세 기능: 공통 (배포 준비)

## 한 일
- 아이콘 원본(`assets/icon/app_icon.png`, `app_icon_mono.png`, `app_icon_background.png`)과 Android 리소스 생성 스크립트(`tool/gen_android_icon.py`)를 추가했다.
- adaptive icon(앞면 · 배경색 · 테마 아이콘 monochrome)과 원형 아이콘 정의, 옛 기기용 `ic_launcher.png`를 교체했다.

## 바꾼 설정
- `AndroidManifest.xml`: `android:roundIcon="@mipmap/ic_launcher_round"` 추가
- adaptive 배경은 `mipmap-*/ic_launcher_background.png` (사각형을 색 번짐으로 채움)
- `res/mipmap-anydpi-v26/ic_launcher.xml` · `ic_launcher_round.xml` 추가, `mipmap-*/ic_launcher*.png` 추가 · 교체
- 새 패키지 · 의존성 없음 (스크립트는 개발 PC에서 Pillow로만 실행)

## 확인
- 이 환경에서는 Flutter 빌드를 못 했다. PC에서 `flutter analyze` · `flutter build apk --debug` 후 설치해 홈 화면 · 앱 목록 · 설정 앱 정보의 아이콘, 원형 · 둥근 사각형 마스크, Android 13+ 테마 아이콘을 확인한다.

## 남은 일 · 질문
- 음표가 원형 마스크에서 살짝 잘려 보이면 `tool/gen_android_icon.py`의 크기 값을 조정한다.
- 시작 화면 음표(`ic_launch_note`)는 그대로 두었다. 같은 마크로 바꿀지 정해야 한다.
- iOS · Windows 아이콘은 Android 이후.
