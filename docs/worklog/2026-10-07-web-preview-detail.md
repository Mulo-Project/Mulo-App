## 한 일
- 원인: 웹(사운드클라우드) 곡은 yt-dlp가 가장 좋은 오디오로 HLS(`m3u8`, `hls_aac_160k`)를 골라 준다. HLS는 조각 목록이라 플레이어가 못 열면 앱이 대신 받아 넘기는 방식(`_HttpRangeSource`)도 쓸 수 없어, 미리 듣기가 실패 대신 시간 초과로 끝났다. (이 PC에서 yt-dlp로 확인: 기본 선택은 `hls_aac_160k`, 한 파일 형식 `http_mp3_1_0`도 있다.)
- 수정: 유튜브가 아닌 주소는 `bestaudio[protocol^=http]`(한 파일 HTTP 형식)를 먼저 고른다 (`ytDlpAudioSelector(web: true)`). 그래도 HLS · DASH 주소만 있으면 앱 HTTP 방식으로 넘기지 않고 바로 실패로 알린다.
- 웹 곡 상세: 유튜브 상세와 따로 `WebMediaDetail`을 만들었다. 맨 위에 사이트 이름 · 아이콘 · "웹 검색 결과", 정사각 커버 아래에 제목 · 아티스트를 가운데로, 길이 · 재생 수 · 올린 날은 한 줄로. 채널 · 구독자 · 영상 보기 문구는 없고 버튼은 "{사이트}에서 열기" · 받기. 사이트 이름은 주소에서 알아낸다 (`MediaSite`, 모르는 사이트는 도메인).
