# 가사 편집 페이지 · 싱크 화면 정리

- 날짜: 2026-10-03
- 분류: 앱 · 디자인
- 상태: 완료
- 브랜치 · 커밋: `feature/lyrics-menu-move`
- 상세 기능: 가사 (싱크 · 편집)

## 한 일
- 가사 화면 위쪽 설정 아이콘과 메뉴를 없앴다. 하단 `싱크 설정` · `가사 편집`은 오른쪽 정렬, 가사가 있을 때만 보인다.
- 가사 편집을 다이얼로그에서 전체 페이지로 뺐다. 취소 · 저장은 알림창처럼 한 줄(`PlainButton`), 싱크 맞추기 버튼과 "시간 표시 = 싱크 가사" 안내를 뺐다.
- 싱크 화면: `지금` · 재생 · 되돌리기는 강조 버튼(`PillButton` · `CircleIconButton`) 복원. 줄을 고르면 `이 싱크로`(다시 듣기)는 왼쪽, ± 시간은 오른쪽.
- 싱크 화면 첫 진입에서 한 번에 묶을 줄 수(1~4, 기본 1)를 고른다. 찍기 시작하면 고정. 묶인 줄은 공백으로 이어 한 줄 LRC로 저장.

## 바꾼 설정
- `AppTextField`에 `expands` 추가 (주어진 높이 전체를 채우는 여러 줄 입력칸).
- ARB: 편집 안내 · 불러오기 문구 단축, `lyricsSyncReset` · `lyricsSyncGroup` · `lyricsSyncGroupLines` 추가, 안 쓰는 메뉴 문구 삭제.
