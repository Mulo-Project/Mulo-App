# 유튜브 분류 읽기 · 검색창 유튜브 표시 정리

- 날짜: 2026-10-06
- 분류: 앱 · 디자인
- 상태: 완료
- 브랜치 · 커밋: `feature/search-youtube-category`
- 상세 기능: 키워드 검색 (#2) · 공통 작업 (디자인 시스템)

## 한 일
- 유튜브가 영상에 붙인 분류(yt-dlp `categories`)를 `MediaHit.categories`로 읽는다 (로컬 · 서버 엔진). 검색 결과 제목 아래에 분류 필터 팝업(전체 + 유튜브 고정 분류 15개, 바로 보임)과 정렬 팝업(관련도 · 인기순 · 최신순 · 짧은 순 · 긴 순 · 제목순)을 두고 누르면 그 분류의 곡만 남는다. 목록 항목에는 분류가 없어 `SearchCubit`이 곡마다 정보를 8곡씩 뒤에서 읽어 채운다 (읽은 곡부터 필터에 걸림, 알아낸 분류는 기억). 결정은 D-057.
- 검색창의 유튜브 표시(`YoutubeMark`)를 `CustomPainter`로 다시 그렸다. 삼각형이 상자를 꽉 채우던 것을 절반 높이 둥근 삼각형으로 줄여 깔끔하게.
- 더 보기 버튼을 무한 스크롤로 바꿨다 (맨 아래 줄이 보이면 다음 쪽).
- `AppDropdown` 메뉴 글자를 `Flexible` + 말줄임으로 (긴 분류 이름 대비).

## 바꾼 설정
- 없음 (새 패키지 · 에셋 없음). ARB에 `videoCategory`(select) 추가. `windows/flutter/generated_plugin*` 변경분은 무관해 포함하지 않았다.

## 확인
- `flutter analyze` 0, `flutter test` 통과 (엔진 파싱 3건 · 필터 · 뒤에서 채우기 · 화면 필터 추가).
- yt-dlp를 이 PC에 설치하지 않아 실제 유튜브 응답으로는 확인하지 못했다. `categories`는 yt-dlp 정보 JSON에 들어 있는 필드이고, 목록(`--flat-playlist`) 항목에는 없다는 점은 yt-dlp 동작에 따른 것이다.

## 남은 일 · 질문
- 유튜브 분류는 `Music` 등 큰 갈래뿐이라 장르(록 · 힙합)로는 못 쓴다. 장르가 필요하면 제목 · 태그(`tags`) 기반 추정이나 YouTube Music 메타데이터가 필요하다.
- 필터를 위해 목록 곡마다 정보를 한 번씩 더 읽는다 (3곡씩 병렬). 느리거나 부담이면 보이는 항목만 읽기 · 읽는 수 제한을 검토한다.
