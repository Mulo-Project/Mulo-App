# 새 재생목록 만들기를 재생목록 선택 대화상자로 이동

- 날짜: 2026-10-06
- 분류: 앱 · 디자인
- 상태: 완료 (PR 대기)
- 브랜치 · 커밋: `feature/playlist-create-in-picker`
- 상세 기능: 받기 팝업 · 공통 작업 (디자인 시스템)

## 한 일
- 받기 팝업(바텀시트)에서 "새 재생목록" 입력칸 · + 버튼을 뺐다.
- 재생목록 선택 대화상자 아래에 이름 입력칸 · + 버튼을 넣었다. 만들면 목록에 나타나고 바로 선택된 상태가 된다 (Enter로도 만들어진다).
- `showPlaylistPickerDialog`가 재생목록 목록을 인자로 받지 않고 `PlaylistsCubit`을 직접 보므로, 만든 목록이 대화상자 안에서 바로 갱신된다.

## 바꾼 설정
- 없음 (새 패키지 · 에셋 · ARB 키 없음, 기존 `downloadNewPlaylist(Hint)` 재사용).
