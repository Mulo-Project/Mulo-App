# 저장 받기 속도 개선 · 저장 완료 알림

- 저장(보관) 받기를 한 줄로 차례로 받던 것을 바꿨다: 주소(영상 · 소리)를 동시에, 한 주소는 4MB 조각으로 나눠 4개씩 동시에 받는다 (유튜브는 한 줄 요청의 속도를 깎아서 조각 요청이 훨씬 빠르다). `StreamCache.fillSaved`.
- 미리 듣기로 이미 임시 저장소에 쌓인 부분은 다시 내려받지 않고 임시 저장소에서 읽어 옮긴다 (임시 저장소에는 새로 쓰지 않는다).
- 받는 동안 진행률(%)을 네이티브가 `savedProgress`로 보내고 저장한 음원 목록 줄에 "받는 중 42%"로 보인다.
- 곡마다 저장이 끝나면 "저장 완료" 알림 (받기 결과 알림 설정을 따른다, 곡 정보 숨기기 지원).
- 확인 필요(기기): 저장 시간 전후 비교, 진행률 · 완료 알림, 영상 + 소리 둘 다 받는 곡, 이어 받기.
- 저장할 때 상세 정보(제목 · 채널 · 조회수 · 좋아요 · 올린 날 · 길이 · 분류 · 앨범 · 설명)를 `saved_details/<id>.txt`(앱 문서 폴더)에 함께 남기고, 저장을 풀면 지운다. `SavedDetailStore` / `FileSavedDetailStore`. 쓰지 못해도 저장은 막지 않는다.
- 미리 듣기 중 소리가 끊기면(네트워크 끊김 등) 닫지 않고 멈춘 상태로 남기고, 다시 재생을 누르면 주소를 새로 읽어 멈춘 위치부터 이어 튼다 (`PreviewCubit._onFailure` / `_resumeInterrupted`). 기기 확인 필요: 비행기 모드 후 복구.
- 저장한 곡의 상세 정보(설명 · 조회수 · 좋아요 · 올린 날 · 분류 · 채널 · 앨범)를 저장 목록(shared_preferences)에도 함께 남긴다. 앱을 다시 켜거나 오프라인이어도 저장한 곡 상세 화면에 그대로 보이고, 인터넷이 되면 상세 화면이 새로 읽어 갱신한다. 글 파일(txt)은 사람이 열어 보는 사본으로 남는다.
