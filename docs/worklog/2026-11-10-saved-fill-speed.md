# 저장 받기 속도 개선 · 저장 완료 알림

- 저장(보관) 받기를 한 줄로 차례로 받던 것을 바꿨다: 주소(영상 · 소리)를 동시에, 한 주소는 4MB 조각으로 나눠 4개씩 동시에 받는다 (유튜브는 한 줄 요청의 속도를 깎아서 조각 요청이 훨씬 빠르다). `StreamCache.fillSaved`.
- 미리 듣기로 이미 임시 저장소에 쌓인 부분은 다시 내려받지 않고 임시 저장소에서 읽어 옮긴다 (임시 저장소에는 새로 쓰지 않는다).
- 받는 동안 진행률(%)을 네이티브가 `savedProgress`로 보내고 저장한 음원 목록 줄에 "받는 중 42%"로 보인다.
- 곡마다 저장이 끝나면 "저장 완료" 알림 (받기 결과 알림 설정을 따른다, 곡 정보 숨기기 지원).
- 확인 필요(기기): 저장 시간 전후 비교, 진행률 · 완료 알림, 영상 + 소리 둘 다 받는 곡, 이어 받기.
