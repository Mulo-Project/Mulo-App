# 유튜브 재생목록 가져오기

- 날짜: 2026-10-07
- 분류: 앱
- 상태: 완료 (merge 대기)
- 브랜치 · 커밋: `feature/youtube-playlist-import`
- 상세 기능: 유튜브 재생목록 가져오기 (#22)

## 한 일
- 가져오기 화면: 주소 입력 → 곡 목록(썸네일 · 채널 · 길이) → 전체 선택 / 일부 선택 → "N곡 받기".
- 받기를 시작하면 유튜브 재생목록 이름의 새 재생목록을 만들고 고른 곡을 받기 대기열에 넣는다. 곡은 받기가 끝나면 그 재생목록에 담긴다. 커버는 재생목록 대표 이미지(웹 이미지).
- 진입점: 재생목록 탭의 가져오기 버튼, 검색 탭에서 재생목록 주소를 찾은 결과의 "골라서 받기".
- `PlaylistInfo.thumbnailUrl` 추가 (로컬 엔진 · 서버 엔진).
- 결정: D-071.
