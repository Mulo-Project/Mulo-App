## 한 일
- 가사 설정 페이지 취소 · 저장을 강조된 알약 버튼으로 키웠다.
- 파일 · 웹에서 가져올 때 가사가 이미 있으면 "바꾸기 / 뒤에 붙이기 / 취소"를 묻는다.
- 웹 가져오기의 "모은 글" 칸 높이를 위쪽 손잡이를 끌어 조절한다.
- 싱크 설정: 일반 글이면 들어갈 때 기본 줄 수를 묻는다 (싱크 가사는 묻지 않음).
- 위쪽 더 보기 메뉴로 기본 줄 수를 바꾼다. 직접 묶은 줄 · 찍은 시간이 있으면 사라진다는 경고 후 적용.
- 찍은 싱크를 누르면 나오는 영역의 더 보기 메뉴 › 줄 묶기: 묶을 마지막 줄을 누르거나 끌어 한 싱크의 줄을 정한다 (남는 줄은 기본 줄 수로 다시 나뉘고, 해당 싱크 시간은 다시 찍는다).
- 재생 위치 / 전체 시간을 몇 줄 남았는지 보이는 위쪽으로 옮겼다.
