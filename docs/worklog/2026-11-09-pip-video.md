# 영상 작은 창(PiP) (2026-11-09)

D-156. #159(영상 네이티브 텍스처) 위에 쌓은 작업. 자세한 방식은 decisions.md.

## 변경
- Manifest: `supportsPictureInPicture`, `resizeableActivity`.
- `MainActivity`: `onUserLeaveHint`에서 PiP 진입, `onPictureInPictureModeChanged`에서 `pip` 이벤트 · 재생 버튼 수신기 등록/해제, PiP 중에는 가사 창이 겹치지 않게 앱이 보이는 것으로 처리.
- `VideoSurfaceHub`: `pipSize` · `isPlaying` · `setPlaying` (미리 듣기는 `PreviewChannel`이 연결).
- Dart: `VideoSurfaceEvent.pip` → `VideoSurfaceState.pip` → `app.dart`의 `_PipSwitcher`가 영상만 꽉 채움.

## 한계
- 영상이 화면에 붙어 있고(미니 플레이어 · 상세 · 플레이어) 재생 중일 때만 진입한다.
- YouTube 미리 듣기에서 작은 창 버튼으로 멈추면 앱의 미리 듣기 화면 상태는 앱으로 돌아와도 바로 갱신되지 않을 수 있다 (소리는 멈춘 상태).

## 확인 필요 (클라우드 환경이라 빌드 · 테스트 못 함)
- PC: `dart format`, `flutter analyze`, `flutter test`, Android 빌드.
- 기기: 영상 곡 재생 중 홈 → 작은 창, 재생/일시정지 버튼, 창을 눌러 앱 복귀, 창 닫기, YouTube 미리 듣기에서도 동일, 영상 없는 곡은 PiP 안 뜸.
