# 작업 기록

작업 하나 = 파일 하나. 파일 이름: `YYYY-MM-DD-<요약>.md` (영어 소문자 · 하이픈).
같은 파일이 Notion [작업 현황 › 작업 기록 DB](https://app.notion.com/p/3eac450c43a581dca8caf650a6d030a8)의 한 행이 된다 (DB `문서` 칸에 이 경로).

## 형식
```markdown
# <작업 이름>

- 날짜: YYYY-MM-DD
- 분류: 기획 · 디자인 · 앱 · 서버 · 설정 · 문서 (여러 개 가능)
- 상태: 진행 중 · 완료 · 보류
- 브랜치 · 커밋: `feature/...` · `abc1234`
- 상세 기능: Notion 상세 기능 이름 (#ID)

## 한 일
## 바꾼 설정
## 확인
## 남은 일 · 질문
```
