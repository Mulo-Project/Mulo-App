# 저장한 음원 재생 목록 → 메인 재생 목록 통합

- 저장한 음원 페이지의 재생 · 셔플 · 반복 · 대기열 버튼과 타일 ⋮ 메뉴가 메인 현재 재생 목록(`NowPlayingCubit`)을 쓴다. 끝까지 받은 곡만 `saved:<id>` 곡으로 올린다. 결정 D-161 (D-160 대체).
- 타일 상세 화면은 하단 고정 조작부(진행 막대 · 10초 · 이전/재생/다음 · 셔플 · 반복 · 대기열)가 메인 재생을 따라가고, 곡이 넘어가면 상세도 넘어간다.
- 임시 저장 곡은 재생 기록 · 재생 횟수를 남기지 않는다. 오프라인이어도 받아 둔 데이터로 튼다.
- 소리만 저장한 곡의 상세에서는 온라인일 때 영상도 재생한다. 한 곡 반복은 3단계 반복(끔 → 목록 → 한 곡)로 메인과 같다.
- 변경: `PlaybackHub.kt`(http 음원을 스트림 캐시로 읽는 미디어 소스 추가), `Track.source=saved`, `PlayRecorderCubit`, 저장 화면 · 상세 · 조작부, 미니 플레이어/알림의 미리 듣기 큐 분기 삭제, `PreviewCubit` 큐 삭제.
- 확인 필요(PC · 실기기): `flutter analyze`, `flutter test`, Android 빌드(Kotlin은 클라우드에서 빌드하지 못함). 임시 저장 곡 목록 재생 · 오프라인 재생 · 알림 이전/다음 · 재생 기록에 안 남는지.
