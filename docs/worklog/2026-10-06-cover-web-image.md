# 커버 이미지를 웹에서 가져오기 · 확대 / 위치 맞추기

- 날짜: 2026-10-06
- 분류: 앱
- 상태: 완료 (PR 대기)
- 브랜치 · 커밋: `feature/covers-web-image`
- 상세 기능: 커버 이미지 설정 (웹 검색 · 위치 맞추기)

## 한 일
- 커버 이미지를 기기 사진 외에 웹 이미지(주소 붙여 넣기 · 검색 결과에서 고르기)로도 정할 수 있다. 웹 이미지는 파일을 받지 않고 주소만 저장한다.
- 이미지를 정할 때 위치 맞추기 화면이 뜬다 (끌어 옮기기 · 두 손가락 / 마우스 휠 / 막대로 확대). 꾸미기 시트의 "위치 조정"으로 다시 맞춘다.
- 확대 · 위치는 `CoverTransform`(배율 · dx · dy)으로 저장하고, `CoverImageProvider`가 잘라 낸 이미지로 어디서든 같은 모양으로 보인다.
- `CoverCubit`의 상태가 키 → `CoverArt`(파일 경로 또는 웹 주소 + 위치)로 바뀌었다. 앨범 이름 바꾸기도 웹 이미지 · 위치를 그대로 옮긴다.

## 바꾼 설정
- DB 스키마 8 → 9: `covers`에 `url` · `scale` · `dx` · `dy` 열 추가 (기존 행은 기본값, 코드 생성 `app_database.g.dart` 포함).
- 새 패키지 · 에셋 · 네이티브 변경 없음. 문구(ARB) 추가.

## 확인
- `flutter analyze` 0, `flutter test` 통과 (저장소 · 큐브 · 잘라 내기 계산 · 위젯 흐름). 실제 기기 확인은 못 했다.

## 남은 일 · 질문
- 웹 "검색"은 유튜브 검색 결과의 대표 이미지다. 구글 이미지 같은 진짜 이미지 검색은 API 키가 필요해 넣지 않았다.
- 곡 파일의 내장 앨범 아트는 아직 읽지 않는다 (별도 기능).
