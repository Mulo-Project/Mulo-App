Mulo

Music downloader & player / 음악 다운로더 & 플레이어

About

Mulo is a music app (Android, Windows, macOS, Linux) that saves audio the user chooses and plays it in the same app, with playlists, a queue, lyrics and a lock-screen player.

Mulo는 사용자가 고른 음원을 저장하고 같은 앱에서 재생하는 음악 앱입니다. 재생목록 · 대기열 · 가사 · 알림 재생을 지원합니다.

Google sign-in (optional)

Signing in with Google is optional. It is used only to show the user's own YouTube playlists inside the app so they can pick songs to import. Mulo requests the read-only scope https://www.googleapis.com/auth/youtube.readonly, never changes anything in the user's YouTube account, and keeps no copy of that data outside the device.

구글 로그인은 선택 사항이며, 내 유튜브 재생목록을 앱에서 보여 주고 가져올 곡을 고르는 데에만 씁니다. 읽기 전용 범위만 요청하며 유튜브 계정을 바꾸지 않습니다.
